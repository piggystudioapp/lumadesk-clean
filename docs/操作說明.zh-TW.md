# LumaDesk 操作說明

LumaDesk 只整理桌面「圖示」。檔案、資料夾、程式、腳本與捷徑都留在原本的路徑，分組只是參照：不搬移、不複製、不改名，也不變更隱藏屬性。

## 開始使用

執行 `lumadesk.exe` 後會出現 LumaDesk 視窗，桌面上會建立分組。關閉視窗後程式仍在系統匣執行；雙擊系統匣圖示可再次開啟，右鍵可開啟選單。一般視窗會蓋住桌面分組，按 Win+D 或視窗中的「顯示分組」即可看到。

## 自動整理

1. 按「自動整理桌面」。LumaDesk 會掃描個人與公用桌面的最上層，列出預覽。
2. 預覽依類型分為應用捷徑（.url）、文件、圖片、影音、壓縮檔、資料夾、程式（含 .lnk 捷徑）、腳本、其他。預設全選，可用 Ctrl／Shift 調整。
3. 按「開始整理」。圖示會顯示在分組裡，Explorer 桌面不重複顯示；檔案總管仍能在原路徑找到所有檔案。

隱藏、系統、連結、尚未下載的雲端項目，以及 `desktop.ini`、`Thumbs.db` 會留在原位並列出原因。每個分組最多 160 個項目。

「自動收納桌面新檔案」（預設開啟）會把之後新出現在桌面的檔案放進對應的分組。原本就在桌面上的項目不受影響；下載中的檔案會等到取得最終檔名再處理。

## 分組操作

| 操作 | 結果 |
| --- | --- |
| 拖曳標題列 | 移動分組；靠近其他分組或螢幕邊緣會自動對齊，按住 Alt 可自由放置 |
| 拖曳右緣、下緣或右下角 | 調整大小 |
| 項目拖到另一個分組 | 移到該分組 |
| 在分組內拖曳 | 調整順序（插入到目標項目之前或最後） |
| 項目拖到 Windows 桌面 | 取消分組，原桌面圖示恢復顯示 |
| 右鍵「從分組移除（保留檔案）」 | 只移除參照，檔案不動 |
| Delete／Shift+Delete | 與檔案總管相同：刪除到資源回收筒／永久刪除（有 Windows 確認） |
| 刪除分組 | 移除分組與其參照，檔案不動 |

- 雙擊或 Enter 開啟項目；右鍵顯示 Windows 原生的檔案選單，再加上 LumaDesk 的指令。
- F2 重新命名選取的檔案；沒有選取時重新命名分組。
- Ctrl／Shift 點選多選，Ctrl+A 全選，Ctrl+F 搜尋。直接輸入文字可跳到名稱相符的項目。
- 「重新排列分組」會在各螢幕內把分組排成不重疊；「找回分組」會把跑出畫面的分組移回主螢幕。
- Ctrl+Z 可復原最近的操作，最多 20 筆，重新開啟程式後仍可使用；沒有重做。

## 檢視與大小

每個分組可從右鍵或 ··· 選單的「檢視」切換大圖示、小圖示、清單、詳細資料，並在「排序方式」依名稱、修改日期、類型或大小排序（資料夾一律在前）。詳細資料的欄寬可拖曳調整，雙擊分隔線可自動調整寬度，在欄位標題按右鍵可選擇要顯示的欄位。

在分組上按 Ctrl＋滑鼠滾輪，或從「檢視」選單，可調整項目大小（小、中、大、特大、超大）。系統匣選單的「所有分組的大小」會一次套用到全部分組。

## 介面語言

支援繁體中文、简体中文、English、日本語、한국어、Deutsch、Français、Español、Português (Brasil)、Русский、Tiếng Việt、ไทย。預設跟隨 Windows 顯示語言；可在 LumaDesk 視窗「更多 → 語言」或系統匣選單即時切換，不需重新啟動，選擇會存在設定中。

切換語言不會改名已有的分組；自動整理會沿用以任何語言命名的同類分組，只有新建立的分類分組使用目前的語言。詳細資料的日期與數字格式跟隨所選語言；「類型」欄由 Windows 提供，維持 Windows 的語言。除繁體中文外，翻譯為機器翻譯。

## 圖示顯示與還原

LumaDesk 透過 Explorer 的桌面圖示位置介面，把已分組的原圖示暫時移到可視範圍外，再在分組中顯示。這只改變畫面位置，不動檔案。

取消分組或從系統匣「結束 LumaDesk」時，會還原原圖示位置與原本的自動排列、格線設定；若 Windows 開啟格線對齊，位置可能依格線調整。另有獨立的監護程序，在主程式意外停止時還原圖示；Explorer 暫時無法使用時會保留位置紀錄，下次啟動再還原。請勿把 `icon-session-*.json` 當成快取刪除。

## 與其他桌面整理工具

LumaDesk 只管理 Explorer 本身的桌面圖示，不操控其他工具建立的視窗或圖示，也不會結束或更改其他程式。若 Windows 桌面或其上層視窗被停用，LumaDesk 會暫停分組、保留原圖示，並在 LumaDesk 視窗顯示原因。建議不要同時使用其他桌面整理工具。

## 設定與資料

設定存放在 `%APPDATA%\LumaDesk`（`layout.json`，另有自動備份）。開啟「更多 → 開啟設定資料夾」可直接查看。LumaDesk 不連網，也不收集任何資料。

設定檔版本為 3。早期預覽版（0.6 以前）的設定會先備份到 `%APPDATA%\LumaDesk\before-virtual-groups` 再升級；升級不搬動任何檔案，舊版的搬移紀錄不提供復原。

## 安裝與移除

解壓縮 ZIP 後直接執行 `lumadesk.exe`；也可用 `Install-LumaDesk.ps1` 安裝到 `%LOCALAPPDATA%\Programs\LumaDesk`，用 `Uninstall-LumaDesk.ps1` 移除。移除前請先從系統匣結束程式，讓桌面圖示恢復。移除時會保留設定與分組歷史。目前的預覽版尚未數位簽章。
